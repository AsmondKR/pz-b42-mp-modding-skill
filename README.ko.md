# PZ Build 42 멀티플레이 모딩 스킬

검증된 Build 42 근거를 바탕으로 서버 권위형 Project Zomboid 멀티플레이 모드를 제작하는 Agent Skills 호환 패키지입니다.

기본 동작은 읽기 전용입니다. 포함된 쓰기 도구는 명시적으로 승인된 작업공간만 사용하며, 먼저 dry-run 변경 명세를 만들고 기존 파일 덮어쓰기와 경로 이탈을 거부합니다.

## 현재 상태

첫 배포 단위는 로컬 B42 빌드 탐지, 서버 권위 설계 지침, 안전한 신규 모드 스캐폴딩, 우선입장 큐 평가 시나리오를 포함합니다.

## 안전 범위

포함된 도구는 Project Zomboid 설치 폴더, 구독한 Workshop 콘텐츠, 세이브, 자격증명, 운영 중인 서버 설정이나 제3자 모드를 수정하지 않습니다. 단, SKILL.md만으로 임의의 에이전트 전체를 샌드박스 처리할 수는 없으므로 완전한 격리가 필요하면 OS·VM·컨테이너 권한을 함께 사용해야 합니다.

## 주요 사용법

```powershell
python scripts/discover_pz.py --json
python scripts/scaffold_mod.py --help
```

스킬은 설치된 게임 파일에서 이벤트와 API 근거를 먼저 찾고, 클라이언트는 UI와 요청만, 서버는 권한·상태·저장·입장 결정을 담당하도록 에이전트를 유도합니다.
